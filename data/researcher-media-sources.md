# Researcher portrait sources

Reviewed: 2026-09-16.

Nineteen portrait records are linked from official university, institute, or academy pages. Images remain remote; the page does not invent or generate portraits. Names and image context were checked against the source pages. The image links below were extracted from those pages, not constructed from guessed filenames.

Eighteen image URLs returned HTTP 200 with an image content type in a direct read on the review date. Michael Miller's Johns Hopkins image returned HTTP 403 to a direct reader; its source profile identifies the headshot, and the website falls back to initials if the browser also cannot load it. The Harvard Lichtman image was switched to the MCB directory's working CDN after the lab-site image returned 403.

Unknown researchers and image errors show typographic initials. The portrait markup has no links, so it can be used inside roster buttons. Photo source credits are separate links in the selected researcher profile. Images use native lazy loading and descriptive alt text.

Attribution does not establish an unrestricted reuse license. Only the Stéphanie Lacour source explicitly supplied a license in this review: CC BY-SA 4.0, with credit to 2024 EPFL / Nicolas Righetti – Lundi 13. The credit renderer preserves both source and license links.
