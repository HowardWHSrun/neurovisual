# Visual revision checklist

User direction: show relevant pictures and visual explanations directly beside the content in each view. The gallery is a secondary browsing tool; inline visuals are the primary requirement.

## Revision targets

- [x] Overview: prominent photo-led entry point with company and research imagery.
- [x] Company profiles: actual device photographs or manufacturer renders, alongside existing mechanism diagrams and official films.
- [x] Research labs: images on directory cards and directly inside 12 selected profiles, with captions, credits, and 5 university films.
- [x] Technology and organization views: visual explanation in the selected-record panel; sourced device or lab images when matched.
- [x] Methods: labeled diagrams alongside the two selected measurement methods.
- [x] Topics: a subject-specific visual explanation before the reading material.
- [x] Ideas: company pictures alongside scaling strategies; counting illustration beside the counting workflow.
- [x] Researchers and papers: project or method visual alongside the selected record.
- [x] Resources: visual guide to choosing tools, datasets, hardware, and courses.
- [x] Learning paths: visible flow from input to the project outcome.
- [x] Glossary: visual relationship between the main signal-processing terms.
- [x] Study and careers: visual map of the path through research and engineering roles.
- [x] Image viewer: enlarge a picture, retain attribution, switch to a film, close with Escape, return keyboard focus.

## Evidence and scope

Use primary-source images and official video IDs. Clearly identify photographs, manufacturer renders, scientific figures, and illustrative schematics. Preserve full multi-panel figures. Generic schematics describe a method, not a verified reconstruction of a particular team's system. Unpictured profiles remain valid research entries; this is not a claim to have photography for all 75 labs or 399 organizations.

## Required verification

- [x] Build, TypeScript, source/route/data checks.
- [x] Desktop and mobile direct inspection across all revised views.
- [x] Loaded-image checks; source credits and fallbacks.
- [x] Dialog focus, keyboard dismissal, video cleanup on navigation.
Publishing gate: deploy source and generated `dist/`, then require a successful Pages build and matching production asset hashes before reporting completion.
